# Java Learning Journey

This repository documents my journey of learning Java, from the fundamentals to more advanced programming concepts.

I am using this repository to organize my practice programs, examples, and coding challenges as I gradually build my Java programming skills.

## Learning Progression

I am following a gradual learning path, starting with the basics and building toward problem-solving and Data Structures & Algorithms.

### 1. Basics

Introduction to Java, basic syntax, printing statements, variables, and fundamental programming concepts.

### 2. Data Types

Understanding primitive data types, variables, and different types of data in Java.

### 3. Conversions

Learning type conversion and type casting in Java.

### 4. If-Else

Learning conditional statements and decision-making using `if`, `else if`, and `else`.

### 5. Loops

Learning and practicing `for`, `while`, and `do-while` loops.

### 6. Operators

Understanding arithmetic, relational, logical, assignment, bitwise, and other operators in Java.

### 7. Methods

Learning how to create, define, call, and use methods in Java.

### 8. Functions

Practicing reusable blocks of code and applying methods and functions to solve programming problems.

### 9. Arrays

Learning one-dimensional and two-dimensional arrays and solving problems using arrays.

### 10. Strings

Learning how to work with Strings and perform different String operations in Java.

### 11. Challenges

Applying the concepts I have learned through coding challenges and practice problems.

**12.Basic Maths**

Basic maths logic important for DSA logic building.
